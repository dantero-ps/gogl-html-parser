# flexbox

Demonstrates flexbox layout: `flex-direction`, `justify-content`, `align-items`, and `flex-grow`.

## Run

```bash
go run ./examples/flexbox/main.go
```

## Features shown

- `display: flex` with `flex-direction: row` and `flex-direction: column`
- `justify-content: space-between` and `justify-content: center`
- `align-items: center` and `align-items: stretch`
- `flex-grow: 1` vs `flex-grow: 2` proportional sizing
