# basic-html-css

Demonstrates block layout, inline text, CSS colors (hex, rgb, named), borders, and typography (font-size, font-weight, font-style, text-align).

## Run

```bash
go run ./examples/basic-html-css/main.go
```

## Features shown

- Block containers with `margin`, `padding`, `border`
- Headings `h1`–`h3` with `font-size` and `font-weight`
- `color` and `background-color` in `#RRGGBB`, `rgb()`, and named-color formats
- Inline `span` inside block `p`
- `text-align: left | center | right`
- Long-line text reflow
