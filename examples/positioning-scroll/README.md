# positioning-scroll

Demonstrates CSS positioning (`relative`, `absolute`, `fixed`) and scrollable overflow containers.

## Run

```bash
go run ./examples/positioning-scroll/main.go
```

## Features shown

- `position: fixed` — header bar pinned to viewport top
- `position: relative` parent + `position: absolute` child with `top`/`left` offsets
- `overflow: auto` container with tall content — use the mouse wheel to scroll
